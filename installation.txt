### 3. How to Activate and Run

To activate the dedicated Python 3.11 environment in your terminal:

```powershell
conda activate humanmol-xpert
```

To test the engines:

```powershell
# 1. Test AutoDock Vina
vina --help

# 2. Test Biological Engines (UniProt, ChEMBL, Reactome, Biopython)
python -c "import Bio, reactome2py, unipressed, chembl_webresource_client; print('Biological intelligence modules loaded!')"

# 3. Test Machine Learning & Chemistry (PyTorch, PyG, Chemprop)
python -c "import torch, chemprop, torch_geometric; print('PyTorch & Chemprop loaded!')"
```
